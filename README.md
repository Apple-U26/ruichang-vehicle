# 江西瑞昌车辆管理系统

车辆档案、出车收车、维保记录、报销审批、月度统计和 Excel 台账导入导出一体化管理。

## 一键启动

双击 `一键启动.bat`（或 `start.bat`）即可：

1. 自动检测并创建 Python 虚拟环境，安装后端依赖；
2. 自动安装前端依赖并构建页面；
3. 初始化数据库和管理员账号；
4. 启动后端服务并自动打开浏览器；
5. 访问地址：http://127.0.0.1:8000

停止服务请双击 `一键停止.bat`（或 `stop.bat`）。

## Git 同步更新

后续修改代码后，一键推送到 GitHub，再到服务器拉取并部署：

1. 本地双击 `一键同步到服务器.bat`；
2. 脚本会自动提交全部改动并推送到 `origin/main`；
3. SSH 登录服务器执行：

```bash
cd /home/ubuntu/ruichang-vehicle
bash scripts/server-deploy.sh
```

服务器脚本会自动 `git pull`、安装依赖、构建前端、初始化数据库并重启服务。

## 手机登录

1. 电脑和手机连接同一个 Wi-Fi/局域网；
2. 双击 `一键启动手机版.bat`（或 `start-lan.bat`）启动局域网访问模式；
3. 手机浏览器打开 `http://电脑局域网IP:8000`，例如 `http://192.168.1.189:8000`；
4. 使用驾驶员账号登录：`driver / Admin@123456`。

如果手机无法打开，请在 Windows 防火墙中允许 TCP 8000 端口入站。

## 公网访问（不要求同一局域网）

双击 `一键公网访问.bat`（或 `start-public.bat`）：

1. 自动确保后端服务已启动；
2. 自动建立临时公网隧道；
3. 在窗口和 `public-url.txt` 中显示公网地址；
4. 手机在任何网络下打开 `公网地址/mobile` 即可登录。

停止公网访问请双击 `一键停止公网.bat`（或 `stop-public.bat`）。

注意：免费隧道地址每次启动都会变化，电脑重启或隧道断开后需重新运行。需要固定公网地址时，应部署到云服务器或注册固定域名。

腾讯云完整部署教程见 [docs/腾讯云部署教程.md](docs/腾讯云部署教程.md)。

## 手机端程序

手机浏览器直接打开 `http://电脑局域网IP:8000/mobile`，登录后即可使用：

- 里程：出车登记、收车登记，支持上传出车/收车照片；
- 维保：录入维保项目和金额，支持上传维保照片；
- 违章：录入违章类型、地点、扣分、罚款，支持上传违章照片；
- 油费：录入加油量、单价、金额、加油站，支持上传油费照片。

电脑端右上角也有“手机端”入口。

## 车辆账号绑定

- 每辆车可以创建一个驾驶员账号，管理员在“用户管理”中创建用户并选择“绑定车辆”；
- 一台车只能绑定一个账号，重复绑定会提示；
- 驾驶员登录后只能看到和录入自己绑定车辆的数据；
- 未绑定车辆的驾驶员登录后无法录入，需要先联系管理员绑定；
- 当前演示驾驶员 `driver` 已绑定车辆 `京CGH828`。

## 默认账号

所有初始化账号的初始密码均为 `Admin@123456`：

| 用户名 | 角色 |
| --- | --- |
| admin | 系统管理员 |
| vehicle_manager | 车辆负责人 |
| project_manager | 项目负责人 |

## 环境要求

- Windows 10/11；
- Python 3.12 或 3.13（脚本会自动选择，3.14 暂不建议）；
- Node.js 18 或更高版本；
- 本机 MySQL 8.0 服务已启动，并已创建数据库和账号：
  - 数据库：`ruichang_vehicle`
  - 用户：`vehicle_user`
  - 密码：`RcVehicle@2026`

数据库连接配置位于 `backend/.env`，可按实际环境修改。

## 功能说明

- 仪表盘：车辆总数、月度里程、报销金额、费用分类统计；
- 车辆档案：新增、编辑、删除、停用，Excel 导入导出；
- 焊机档案：焊机编码、编号、所在地、所属项目、项目负责人、焊机负责人、状态；
- 焊机编码自动生成（HJ-xxxxxx），选择项目后自动带出项目所在地；支持 Excel 导入导出；
- 焊机巡检：巡检单新增/编辑、附件上传、设备状态、维修说明；故障状态自动同步焊机档案，维修后解除故障并写入备注；
- 巡检日期默认当天，导出时巡检记录按焊机编号自动排序；
- 焊机台账可单独导入，自动生成/修正编码，重复焊机编号自动加 `*` 区分；焊机档案、焊机巡检支持批量删除；巡检支持按月份筛选；
- 里程管理：出车登记、收车登记、异常里程提示；出车/收车照片为必填（最多 6 张），出车里程会同步为车辆当前里程，收车后当前里程自动更新为收车里程；
- 维保管理：保养、维修、年检、保险记录，维保照片必填（最多 6 张）；
- 违章管理：违章记录、扣分、罚款、处理状态，违章照片必填（最多 6 张）；
- 油费管理：加油量、单价、金额、加油站和发票记录，油费照片必填（最多 6 张）；
- 报销管理：可关联当月该车辆油费/维保记录，同一笔油费/维保记录只能关联一张报销单，已使用后自动从选择列表移除；手动费用必须上传图片证明；不同笔报销费用可分别提交，审核简化为“通过 / 退回”，退回必须填写原因；
- 项目管理：项目新增、编辑、停用；
- 用户管理：管理员可维护用户和角色，重置密码；
- Excel：导出车辆、里程、维保、违章、油费、报销、月度汇总工作表。
- 车辆台账和焊机台账可分别导出：车辆台账含车辆及业务记录，焊机台账含焊机档案和焊机巡检；管理员、车辆负责人、项目负责人、财务均可导出。
- Excel 导入兼容《车辆里程维保报销一体化管理》模板，可自动识别标题行并导入车辆、里程、维保、报销数据。

## 删除权限

- 里程管理、维保管理、违章管理、油费管理、报销管理中的记录删除仅限管理员；
- 车辆档案删除仅限系统管理员；
- 车辆、里程、维保、违章、油费、报销、项目管理支持勾选多条后批量删除（仅管理员）；
- 删除车辆后车辆 ID 和车辆编码会重新续号，不产生重复编码；
- 删除焊机后焊机 ID 和焊机编码同样会重新连续编号；车辆/焊机 ID 从 1 开始连续排列；
- 用户管理支持删除用户，系统管理员账号不可删除；
- 报销管理支持勾选多条后批量审核通过；
- 初始里程仅系统管理员可以编辑；
- 车辆负责人、项目负责人、财务、驾驶员账号不会显示删除按钮，调用删除接口也会被拒绝。

## 角色权限

- 驾驶员：里程、维保、违章、油费记录权限；
- 车辆负责人：驾驶员权限 + 报销申请权限；
- 车辆负责人只能编辑“车辆负责人”一栏为自己的车辆，不能编辑其他车辆负责人的车辆；
- 车辆负责人可查看项目管理（只读），不能新增、编辑、删除项目；
- 项目负责人：车辆负责人权限 + 项目管理权限；
- 项目负责人可查看全部项目，只能编辑自己负责的项目；
- 财务人员：只能处理报销管理，其余模块仅查看；
- 管理员：全部权限。

电脑端和手机端菜单均按上述角色权限显示。

## 其他功能

- 登录信息保存在当前设备，登录有效期 30 天，下次打开自动登录；
- 里程记录支持查看出车/收车图片，显示精确到小时的 24 小时制时间；
- 车辆档案支持最多 10 张车辆图片；
- 报销支持“里程补助”费用类型，可从里程记录添加，按 0.2 元/公里自动计算；
- 里程补助报销中可查看出车和收车时上传的两张图片；
- 同一笔油费/维保/里程记录只能关联一张报销单；
- 财务人员可在里程、维保、违章、油费、报销中使用搜索栏快捷查询；
- 财务人员可以编辑违章记录；
- 车辆负责人、项目负责人只显示自己负责范围内的车辆、项目和记录。
- 项目负责人在车辆档案中可以查看全部车辆，但只能编辑自己项目下的车辆。
