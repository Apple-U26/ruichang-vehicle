# 腾讯云部署教程

本教程以腾讯云轻量应用服务器（Ubuntu 22.04）为例，把“车辆管理”部署到云服务器，手机在任何网络下都可以访问。

## 1. 购买并初始化服务器

1. 登录腾讯云控制台，购买“轻量应用服务器”或 CVM；
2. 系统镜像选择 **Ubuntu 22.04 LTS**；
3. 配置建议：2核 2G 起，4G 更稳；
4. 在控制台“防火墙”中放行：
   - TCP 22（SSH）
   - TCP 80（HTTP）
   - TCP 443（HTTPS）
   - 不需要对公网开放 3306；
5. 记录服务器公网 IP，例如 `1.2.3.4`。

## 2. 安装基础环境

SSH 登录服务器后执行：

```bash
sudo apt update
sudo apt install -y git curl tar python3-venv python3-pip mysql-server nginx
```

安装 Node.js 20（使用腾讯云镜像更快）：

```bash
curl -fsSL https://mirrors.cloud.tencent.com/nodesource/setup_20.x | sudo -E bash -
sudo apt install -y nodejs
node -v
npm -v
```

## 3. 安装并配置 MySQL

启动 MySQL：

```bash
sudo systemctl enable --now mysql
sudo mysql
```

在 MySQL 中创建数据库和专用账号：

```sql
CREATE DATABASE ruichang_vehicle CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'vehicle_user'@'localhost' IDENTIFIED BY 'RcVehicle@2026';
GRANT ALL PRIVILEGES ON ruichang_vehicle.* TO 'vehicle_user'@'localhost';
FLUSH PRIVILEGES;
EXIT;
```

> 生产环境建议把密码换成强密码，并同步修改项目配置。

## 4. 上传项目

### 方式一：压缩包上传（推荐）

在本地 Windows 项目目录 `E:\ruichang-vehicle` 的上一级执行：

```powershell
tar --exclude='ruichang-vehicle/frontend/node_modules' --exclude='ruichang-vehicle/backend/.venv' -czf vehicle.tar.gz ruichang-vehicle
```

上传到服务器：

```powershell
scp vehicle.tar.gz ubuntu@1.2.3.4:/home/ubuntu/
```

服务器上解压：

```bash
cd /home/ubuntu
tar -xzf vehicle.tar.gz
```

### 方式二：Git

把项目推送到 Git 仓库后，在服务器上：

```bash
cd /home/ubuntu
git clone 你的仓库地址 ruichang-vehicle
```

以后本地更新代码时：

1. 本地双击 `一键同步到服务器.bat`，自动提交并推送；
2. 服务器执行：

```bash
cd /home/ubuntu/ruichang-vehicle
bash scripts/server-deploy.sh
```

## 5. 配置后端环境

```bash
cd /home/ubuntu/ruichang-vehicle/backend
cp .env.example .env
```

编辑 `.env`，把 `JWT_SECRET` 改成长随机字符串，并确认数据库地址正确：

```bash
nano .env
```

创建虚拟环境并安装依赖：

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## 6. 构建前端

```bash
cd /home/ubuntu/ruichang-vehicle/frontend
npm install
npm run build
```

构建完成后，后端会自动托管 `frontend/dist`，无需单独部署前端。

## 7. 初始化数据库

```bash
cd /home/ubuntu/ruichang-vehicle/backend
source .venv/bin/activate
python -m app.seed
```

初始化会创建：

- 管理员：`admin / Admin@123456`
- 演示账号：`vehicle_manager`、`project_manager`、`finance`、`driver`

## 8. 使用 systemd 常驻运行

创建服务文件：

```bash
sudo nano /etc/systemd/system/ruichang-vehicle.service
```

内容：

```ini
[Unit]
Description=Ruichang Vehicle System
After=network.target mysql.service

[Service]
User=ubuntu
WorkingDirectory=/home/ubuntu/ruichang-vehicle/backend
ExecStart=/home/ubuntu/ruichang-vehicle/backend/.venv/bin/python -m uvicorn app.main:app --host 0.0.0.0 --port 8000
Restart=always

[Install]
WantedBy=multi-user.target
```

启动并设置开机自启：

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now ruichang-vehicle
sudo systemctl status ruichang-vehicle
```

查看运行日志：

```bash
sudo journalctl -u ruichang-vehicle -f
```

## 9. 配置 Nginx

创建站点配置：

```bash
sudo nano /etc/nginx/sites-available/ruichang-vehicle
```

内容：

```nginx
server {
    listen 80;
    server_name 你的域名或服务器IP;

    client_max_body_size 20m;

    location /uploads/ {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    location / {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

启用并重载：

```bash
sudo ln -sf /etc/nginx/sites-available/ruichang-vehicle /etc/nginx/sites-enabled/ruichang-vehicle
sudo nginx -t
sudo systemctl reload nginx
```

### 9.1 访问提速配置（推荐）

项目已提供优化后的 Nginx 配置：`deploy/nginx-ruichang-vehicle.conf`。

把它上传到服务器：

```bash
cd /home/ubuntu/ruichang-vehicle
sudo cp deploy/nginx-ruichang-vehicle.conf /etc/nginx/sites-available/ruichang-vehicle
```

先编辑 `server_name` 为实际域名或服务器 IP：

```bash
sudo nano /etc/nginx/sites-available/ruichang-vehicle
```

然后测试并重载：

```bash
sudo nginx -t
sudo systemctl reload nginx
```

该配置做了三件事：

- 开启 gzip 压缩，减少 JS/CSS 传输体积；
- `/assets/` 静态资源由 Nginx 直接读取并缓存 30 天，不再每次转发给 FastAPI；
- `/uploads/`、`/api/` 仍代理到后端，图片和接口不受影响。

如果已经用 certbot 配置了 HTTPS，不要把整个文件覆盖到 443 的 server 块，只需要把其中的 `gzip` 和四个 `location` 块合并进现有 HTTPS server 块，再执行：

```bash
sudo nginx -t
sudo systemctl reload nginx
```

## 10. 配置 HTTPS（推荐）

### 10.1 没有域名怎么办

没有域名可以直接使用 IP 访问，跳过 HTTPS 配置：

```text
http://服务器公网IP:8000/mobile
```

### 10.2 域名怎么确定

域名需要自己购买，例如：

- `ruichang.com`
- `vehicle.example.cn`
- `rcgz.top`

购买渠道：

- 腾讯云：控制台 → 域名注册；
- 阿里云：控制台 → 域名；
- 其他：Cloudflare、Namesilo 等。

购买后需要把域名解析到服务器：

1. 打开域名服务商的 DNS 解析控制台；
2. 添加 A 记录；
3. 主机记录填写 `@`、`www` 或自定义子域名（例如 `vehicle`）；
4. 记录值填写服务器公网 IP；
5. 等待几分钟到几小时生效，可用 `ping 你的域名` 或 `nslookup 你的域名` 验证。

> 国内云服务器使用域名提供网站服务，域名需要完成 ICP 备案。备案通过前，80/443 端口不能正常对外提供服务。没有备案时，可先用 `http://公网IP:8000` 访问。

### 10.3 使用 Let's Encrypt 配置 HTTPS

域名解析生效后执行：

```bash
sudo apt install -y certbot python3-certbot-nginx
sudo certbot --nginx -d 你的域名
```

之后手机访问：

```text
https://你的域名/mobile
```

### 10.4 域名无法访问排查

#### 检查域名解析

在本地电脑执行：

```powershell
nslookup 你的域名
ping 你的域名
```

如果返回的 IP 不是服务器公网 IP，需要在域名 DNS 控制台添加 A 记录：

- 主机记录：`@` 或 `www`
- 记录值：服务器公网 IP

#### 检查服务器端口

SSH 登录服务器执行：

```bash
sudo ss -tlnp | grep -E ':80|:443'
sudo systemctl status nginx
curl -I http://127.0.0.1/
curl http://127.0.0.1:8000/api/health
```

- 只有 `:80`，没有 `:443`：说明 HTTPS 未配置，先使用 `http://你的域名` 测试；
- `:80` 和 `:443` 都没有：Nginx 未启动或配置报错；
- 80 正常、443 拒绝：执行 certbot 配置 HTTPS。

#### 腾讯云防火墙

在腾讯云控制台“防火墙/安全组”中放行：

- TCP 22
- TCP 80
- TCP 443

#### ICP 备案

如果服务器在腾讯云中国大陆地域，域名绑定 80/443 提供网站服务需要完成 ICP 备案。备案通过前，80/443 可能无法正常对外访问，可先用 `http://服务器公网IP:8000` 访问。

## 11. 验证

浏览器打开：

```text
http://服务器公网IP:8000
```

或使用 Nginx 后：

```text
http://你的域名
```

手机任意网络打开：

```text
http://服务器公网IP:8000/mobile
```

登录 `driver / Admin@123456` 即可使用。

## 12. 安全建议

- 修改 `admin` 默认密码；
- 修改 `.env` 中的 `JWT_SECRET`；
- 腾讯云防火墙只开放 22、80、443；
- 不要把 MySQL 3306 暴露到公网；
- 定期备份数据库：

```bash
mysqldump -u vehicle_user -p ruichang_vehicle > vehicle_backup.sql
```

- 使用 HTTPS 后，把手机端入口改为 `https://你的域名/mobile`。

## 13. Git 自动同步更新

项目根目录已提供：

- `一键同步到服务器.bat`：本地提交全部改动并推送到 GitHub；
- `scripts/server-deploy.sh`：服务器拉取代码、安装依赖、构建前端并重启服务。

部署脚本默认项目目录为 `/home/ubuntu/ruichang-vehicle`，如目录不同可设置环境变量：

```bash
APP_DIR=/home/ubuntu/其他目录 bash scripts/server-deploy.sh
```

仓库已忽略运行文件：`backend/.env`、`.venv`、`node_modules`、`frontend/dist`、`backend/uploads`、日志、备份、临时文件等，不会随代码同步到服务器。

### 13.1 同步照片到服务器

Git 不会同步 `backend/uploads` 中的照片。如果服务器缺少本地已有图片，在本地执行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts\sync-uploads.ps1 -Server ubuntu@你的服务器
```

也可以双击 `一键同步图片到服务器.bat`。脚本会逐个上传本地 `backend/uploads` 下的图片到服务器，并自动创建远程目录。

上传目录统一使用 `backend/uploads` 绝对路径，不受服务启动目录影响。
