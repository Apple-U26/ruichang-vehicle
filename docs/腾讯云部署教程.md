# 腾讯云部署教程

本教程以腾讯云轻量应用服务器（Ubuntu 22.04）为例，把“江西瑞昌车辆管理系统”部署到云服务器，手机在任何网络下都可以访问。

## 1. 购买并初始化服务器

1. 登录腾讯云控制台，购买“轻量应用服务器”或 CVM；
2. 系统镜像选择 **Ubuntu 22.04 LTS**；
3. 配置建议：2核 2G 起，4G 更稳；
4. 在控制台“防火墙”中放行：
   - TCP 22（SSH）
   - TCP 80（HTTP）
   - TCP 443（HTTPS）
   - 不需要对公网开放 3306；
5. 记录服务器公网 IP，例如 `1.2.3.4`。

## 2. 安装基础环境

SSH 登录服务器后执行：

```bash
sudo apt update
sudo apt install -y git curl tar python3-venv python3-pip mysql-server nginx
```

安装 Node.js 20（使用腾讯云镜像更快）：

```bash
curl -fsSL https://mirrors.cloud.tencent.com/nodesource/setup_20.x | sudo -E bash -
sudo apt install -y nodejs
node -v
npm -v
```

## 3. 安装并配置 MySQL

启动 MySQL：

```bash
sudo systemctl enable --now mysql
sudo mysql
```

在 MySQL 中创建数据库和专用账号：

```sql
CREATE DATABASE ruichang_vehicle CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'vehicle_user'@'localhost' IDENTIFIED BY 'RcVehicle@2026';
GRANT ALL PRIVILEGES ON ruichang_vehicle.* TO 'vehicle_user'@'localhost';
FLUSH PRIVILEGES;
EXIT;
```

> 生产环境建议把密码换成强密码，并同步修改项目配置。

## 4. 上传项目

### 方式一：压缩包上传（推荐）

在本地 Windows 项目目录 `E:\ruichang-vehicle` 的上一级执行：

```powershell
tar --exclude='ruichang-vehicle/frontend/node_modules' --exclude='ruichang-vehicle/backend/.venv' -czf vehicle.tar.gz ruichang-vehicle
```

上传到服务器：

```powershell
scp vehicle.tar.gz ubuntu@1.2.3.4:/home/ubuntu/
```

服务器上解压：

```bash
cd /home/ubuntu
tar -xzf vehicle.tar.gz
```

### 方式二：Git

把项目推送到 Git 仓库后，在服务器上：

```bash
cd /home/ubuntu
git clone 你的仓库地址 ruichang-vehicle
```

## 5. 配置后端环境

```bash
cd /home/ubuntu/ruichang-vehicle/backend
cp .env.example .env
```

编辑 `.env`，把 `JWT_SECRET` 改成长随机字符串，并确认数据库地址正确：

```bash
nano .env
```

创建虚拟环境并安装依赖：

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## 6. 构建前端

```bash
cd /home/ubuntu/ruichang-vehicle/frontend
npm install
npm run build
```

构建完成后，后端会自动托管 `frontend/dist`，无需单独部署前端。

## 7. 初始化数据库

```bash
cd /home/ubuntu/ruichang-vehicle/backend
source .venv/bin/activate
python -m app.seed
```

初始化会创建：

- 管理员：`admin / Admin@123456`
- 演示账号：`vehicle_manager`、`project_manager`、`finance`、`driver`

## 8. 使用 systemd 常驻运行

创建服务文件：

```bash
sudo nano /etc/systemd/system/ruichang-vehicle.service
```

内容：

```ini
[Unit]
Description=Ruichang Vehicle System
After=network.target mysql.service

[Service]
User=ubuntu
WorkingDirectory=/home/ubuntu/ruichang-vehicle/backend
ExecStart=/home/ubuntu/ruichang-vehicle/backend/.venv/bin/python -m uvicorn app.main:app --host 0.0.0.0 --port 8000
Restart=always

[Install]
WantedBy=multi-user.target
```

启动并设置开机自启：

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now ruichang-vehicle
sudo systemctl status ruichang-vehicle
```

查看运行日志：

```bash
sudo journalctl -u ruichang-vehicle -f
```

## 9. 配置 Nginx

创建站点配置：

```bash
sudo nano /etc/nginx/sites-available/ruichang-vehicle
```

内容：

```nginx
server {
    listen 80;
    server_name 你的域名或服务器IP;

    client_max_body_size 20m;

    location / {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

启用并重载：

```bash
sudo ln -s /etc/nginx/sites-available/ruichang-vehicle /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl reload nginx
```

## 10. 配置 HTTPS（推荐）

有域名时使用 Let's Encrypt：

```bash
sudo apt install -y certbot python3-certbot-nginx
sudo certbot --nginx -d 你的域名
```

之后手机访问：

```text
https://你的域名/mobile
```

## 11. 验证

浏览器打开：

```text
http://服务器公网IP:8000
```

或使用 Nginx 后：

```text
http://你的域名
```

手机任意网络打开：

```text
http://服务器公网IP:8000/mobile
```

登录 `driver / Admin@123456` 即可使用。

## 12. 安全建议

- 修改 `admin` 默认密码；
- 修改 `.env` 中的 `JWT_SECRET`；
- 腾讯云防火墙只开放 22、80、443；
- 不要把 MySQL 3306 暴露到公网；
- 定期备份数据库：

```bash
mysqldump -u vehicle_user -p ruichang_vehicle > vehicle_backup.sql
```

- 使用 HTTPS 后，把手机端入口改为 `https://你的域名/mobile`。
