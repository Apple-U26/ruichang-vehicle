# 里程报告

在电脑端“里程管理”中点击“导出里程报告”。现有车辆总台账导出入口和登记、审批流程保持兼容。

## 查询与导出

- 页面支持月份或日期范围筛选，两者任选其一，支持按出车或收车时间查询。
- 导出窗口默认沿用已查询的时间范围及关键字；未指定时默认本月截至当天。
- 可选择车辆、驾驶人、状态及照片模式：不附照片、出收车各一张代表照片、全部照片。
- 结束日期包含当天全天；跨期行程按所选出车或收车时间归属，整笔计入，不估算跨期分摊。
- 管理员、财务、项目负责人和车辆负责人可以在原有数据权限范围内导出；驾驶员导出权限不变。

## 报表内容

1. **个人里程汇总**：姓名、出车次数、已收车次数、有效里程、异常待核实里程、未收车次数、涉及车辆数、出车天数及数据待核实次数。
2. **里程明细**：行程编号、车牌、驾驶人、出收车时间、起止里程、本次里程、统计分类、有效与异常里程、照片入口和业务说明。
3. **照片凭证**：按行程编号记录出收车照片。明细中的照片入口可在工作簿内跳转，离线可查看，不包含登录令牌。

姓名去掉前后空格后精确分组；同名跨车辆合并，不自动合并其他写法。空姓名单列“未填写姓名”。

只有已收车、起止里程完整且合理、里程数值一致且无异常标记的记录计入有效里程。异常记录单列待核实；负数或数据不完整的行程不用于抵减有效里程。

出收车时间导出为 Excel 日期时间单元格。收车时间为系统登记时间；旧模板导入可能只有月份，报表保留现有记录，不推断缺失时间。

## 生成和下载

后台生成报告时可继续操作其他功能；完成后点击“下载报告”。离开页面后重新进入，可继续查看此前任务。文件保留6小时，过期后重新生成。

单次最多366天、5000条记录和400张选定照片。照片只在导出时生成压缩副本，原图保持不变；缺失、非图片或无法读取的附件在凭证页说明。

为保护线上服务，生成采用低优先级独立进程、单进程锁、内存限制、任务超时及小队列；超量时请缩小范围或选择不附照片。报表生成不修改业务数据。

## 验证

后端开发环境执行 `python -m unittest discover -s tests -v`。前端使用锁文件对应依赖构建；本次构建环境为 Node.js 24，服务器上的旧版 Node.js 无需升级。
